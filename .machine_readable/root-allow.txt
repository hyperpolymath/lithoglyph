# LITHOGLYPH — repository-specific additions
#
# Lithoglyph is a multi-language database: a Forth model core, a Zig ABI bridge,
# a Factor storage binding, a BEAM control plane and several delivery surfaces.
# Each layer is a separate toolchain with its own build root, so they sit at the
# repository root rather than under src/ — a single src/ would have to contain
# five mutually unaware build systems. Entries are grouped by what they are.
# ═══════════════════════════════════════════════════════════════════════════════
